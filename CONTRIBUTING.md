# Contributing to DocSwift

Thanks for helping improve DocSwift.

## Local development
1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm run dev` and open `http://localhost:5173`.

## Pull requests
- Keep changes focused and explain the user-facing impact.
- Test PDF operations with non-sensitive sample files.
- Preserve keyboard accessibility and responsive layouts.
- Do not commit secrets, API keys, private documents, or user data.
- State limitations honestly; do not make unsupported privacy or compression claims.

## Security reports
Avoid posting sensitive files or exploit details in public issues. Contact the maintainer privately through GitHub if a private reporting channel is available.
